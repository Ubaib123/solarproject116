# 🌞 Surya-Shakti Solar Monitor

A smart Android application built using GenAI concepts to help users monitor and manage solar energy generation and consumption efficiently. This project provides a simple dashboard for tracking daily solar power production, electricity usage, and overall savings.

---

## 📱 Project Overview

Many households with rooftop solar panels struggle to understand:

- How much energy they generate
- How much electricity they consume
- Whether they are saving money
- Best times to use heavy appliances

The **Surya-Shakti Solar Monitor** solves this problem by offering a visual and user-friendly energy monitoring system.

---

## 🚀 Features

### ✅ Generation Log
- Users can manually enter or simulate daily solar energy generation (kWh).

### ✅ Consumption Tracker
- Track electricity consumption using meter readings.

### ✅ Savings Calculator
- Calculates daily and monthly electricity savings.

### ✅ Peak Usage Suggestions
- Suggests ideal times to use heavy appliances.

### ✅ Solar vs Grid Visualization
- Circular Progress Bar to display solar usage ratio.

### ✅ Monthly Reports
- View 30-day energy and savings reports.

### ✅ Over-Generation Handling
- Detects excess energy generation and export-to-grid scenarios.

### ✅ Smart UI
- High-contrast yellow/black theme for outdoor readability.

## 📊 How It Works

1. User enters daily solar generation.
2. App records electricity consumption.
3. System calculates:
   - Net Usage
   - Savings
   - Exported Energy
4. Dashboard displays analytics visually.
